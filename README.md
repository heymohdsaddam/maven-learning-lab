# 🚀 Maven Learning Lab

A hands-on learning repository dedicated to understanding **Apache Maven** and its practical application in Java development.

This repository documents my journey of learning Maven, starting from the fundamentals and progressing towards advanced concepts through practical examples, demonstrations, and mini-projects.

The goal is to develop a strong understanding of Maven as a build automation and dependency management tool used in real-world Java projects.

---

## 🎯 Objectives

- Understand Apache Maven and its architecture.
- Learn Maven project structure and the `pom.xml` configuration.
- Understand dependency management and transitive dependencies.
- Explore Maven build lifecycle and phases.
- Work with Maven plugins and goals.
- Learn Maven repositories and dependency resolution.
- Understand Maven profiles and multi-module projects.
- Apply Maven concepts through practical Java projects.

## ⚡ Common Maven Commands

| Command | Description |
|---|---|
| `mvn -version` | Check Maven installation |
| `mvn clean` | Remove previous build files |
| `mvn compile` | Compile source code |
| `mvn test` | Execute test cases |
| `mvn package` | Package the application |
| `mvn install` | Install artifact into local repository |
| `mvn clean install` | Clean and build the project |
| `mvn dependency:tree` | Display dependency hierarchy |
| `mvn validate` | Validate project configuration |
